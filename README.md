# Reception Invitation Website

A cinematic wedding/reception invitation built with React, Vite, Framer Motion and CSS.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Customize

The easiest place to edit all invitation information is:

`src/data.js`

Change the groom/bride names, Nikah date/time/venue, reception date/time/venue, quote, closing message and signature.

## Deploy

Build with:

```bash
npm run build
```

The production files will be in `dist/`. This can be deployed directly to Vercel or Netlify.
